# Lumeny

Built with React 19, TypeScript and Vite (React Compiler enabled).

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Structure

- `src/components/<Name>/<Name>.tsx` + `<Name>.module.css` — one folder per component, styled with CSS Modules
- `src/styles/variables.css` — design tokens (colors, radii, fonts)
- `src/styles/index.css` — global reset and base styles
